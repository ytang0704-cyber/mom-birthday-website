# 妈咪生日礼物网站 🎂

一个手机优先的静态网页，送给妈妈 50 岁生日。她会在微信里点开链接，独自看完：午后房间 → 贺卡 → 时间日记 → 吹蜡烛 → 读信。

- 纯 HTML / CSS / 原生 JS，**零外部依赖**（不加载任何 CDN、字体或脚本），国内微信打开也不受影响。
- 所有文案和素材路径集中在 `js/config.js`，改内容不用碰代码。
- 手机竖屏 360–430px 已适配：正文 ≥17px、触摸区 ≥44px、无横向溢出、支持"降低动效"。

## 二、本地预览

**不要**直接双击 `index.html` 打开（`file://` 协议下浏览器会禁止麦克风，也容易路径出错）。请起一个本地服务器：

```bash
cd ~/Desktop/mom-birthday-website

# 方式一：Python（macOS 自带）
python3 -m http.server 8000

# 方式二：Node（若已安装）
npx serve .
```

然后手机和电脑连同一个 Wi-Fi，用手机浏览器访问 `http://<电脑的局域网IP>:8000` 即可在手机上预览（微信内先测链接，麦克风在手机上仍需 HTTPS，见下文）。

## 三、改内容（重点：只需改 `js/config.js`）

打开 `js/config.js`，顶部每个字段都有中文注释。常用修改：

| 想改什么 | 改哪里 |
| --- | --- |
| 妈妈称呼、年龄、生日日期、署名 | `mom` / `from` |
| 贺卡封面字、开场祝福 | `card` |
| 日记的每则回忆（时期、日期、标题、文字、图片/视频/语音） | `diary.memories` |
| 蛋糕的许愿提示、吹灭祝福 | `cake` |
| 生日信正文、我的录音 | `letter` |
| 背景音乐文件 | `sound.backgroundMusic` |

**回忆（`diary.memories`）字段说明：**

```js
{
  id: "m1",
  period: "before",     // before=出国前 / after=离开后 / now=现在
  date: "2026年7月",    // 日期
  title: "标题",
  text: "50–100 字的正文",
  images: ["assets/images/mem1-1.jpg", "assets/images/mem1-2.jpg"],  // 1–3 张，可放大
  video: "",            // 可选，短视频路径；留空则不显示
  audio: "",            // 可选，语音路径；留空则不显示
},
```

> 留空的媒体字段会自动隐藏对应播放器。当前 `config.js` 里所有文案都是**占位示例**，记得换成你真实的回忆和话。

## 四、替换素材

1. 把文件放进对应目录：图片 → `assets/images/`、音频 → `assets/audio/`、视频 → `assets/video/`。
2. 在 `config.js` 里把字段改成相对路径，例如 `"assets/images/mem1-1.jpg"`。
3. 建议：
   - **图片先压缩**（单张尽量 < 300KB），照片可用 `sips` 或在线工具压到宽 800–1200px。
   - 音频用 `.mp3` 或 `.m4a`，视频用 `.mp4`（H.264，微信/iPhone 兼容最好）。
   - **背景音乐**：放一个轻柔的循环片段到 `assets/audio/bgm.mp3`，并在 `config.js` 的 `sound.backgroundMusic` 填 `"assets/audio/bgm.mp3"`。**不填**也没关系，网站会用内置的"轻音乐盒"音色。
   - **我的祝福录音**：录好后放 `assets/audio/blessing.m4a`，在 `letter.recording` 填路径。**不填**则退化为手机"文字转语音"朗读这封信。

## 五、部署到 HTTPS（微信里用麦克风的前提）

吹气检测需要麦克风，而浏览器只允许在 **HTTPS**（或 localhost）下用麦克风，所以正式发给妈妈时必须是 `https://` 开头的链接。选一个即可：

### 方案 A：GitHub Pages（免费、最简单，推荐）
1. 把整个文件夹上传到 GitHub 仓库（可用 GitHub Desktop 或 `git`）。
2. 仓库 → Settings → Pages → Source 选 `main` 分支 → 保存。
3. 得到 `https://<你的用户名>.github.io/<仓库名>/`，把链接发给妈妈即可。GitHub Pages 自带 HTTPS。

### 方案 B：Vercel / Netlify（免费、自动 HTTPS）
1. 注册并导入这个文件夹（或 GitHub 仓库）。
2. 平台会自动生成 `https://…` 的网址。

### 方案 C：自己的服务器 / 域名
1. 把 `index.html` 及 `css/`、`js/`、`assets/` 一起上传到网站根目录。
2. 给域名配置 HTTPS 证书（腾讯云/阿里云可免费申请，或用 Let's Encrypt）。

> 本项目是纯静态文件，**不需要任何构建步骤**，上传即用。

## 六、在妈妈手机微信里自测（验收清单）

> ⚠️ 我无法替你做真机测试。请在妈妈实际手机上、用微信打开 `https://` 链接，逐项检查：

- [ ] 竖屏 360–430px 下页面没有左右滑动（无横向溢出）
- [ ] 正文文字 ≥17px，按钮/可点区域 ≥44px，好点不误触
- [ ] 首次进入点桌上贺卡 → 展开 → 读开场祝福
- [ ] 日记可左右滑动/点箭头翻页，照片点击可放大，视频/语音能播（若有）
- [ ] 蛋糕：先点许愿 → 麦克风授权 → 对着手机底部吹气火苗会摇动并熄灭（或点"点这里吹灭蜡烛"也能过）
- [ ] 声音默认是关的，点右上角"开启声音"后能听到背景音乐/音效；录音或视频播放时背景音乐自动变小
- [ ] 吹灭后出祝福 → 读信 → 回房间出现"再读生日信/再看日记/再看蛋糕/重播整个流程"
- [ ] 切换后台或退出流程后，麦克风已释放（状态栏不再显示"正在使用麦克风"）

**吹气是原型**：微信内置浏览器的 WebView 版本较旧，麦克风授权/识别可能不稳定。这是预期内的——任何时候都能用"点这里吹灭蜡烛"兜底，请以"能走完流程"为准，不要卡在吹气识别上。

已知需真机确认的项（如果暂时测不了，请如实标注"待验证"，不要声称已通过）：
- 微信 WebView 中麦克风授权弹窗与吹气识别的实际表现
- 不同机型火苗位置是否仍对准蜡烛（极窄/极宽屏可能略有偏移，可用 `css/style.css` 里 `#flame` 的 `top` 微调）

## 七、常见问题

- **打开是白屏 / 报错？** 可能是用了 `file://` 直接打开，请用第二节的本地服务器。
- **微信里点"许愿"没反应？** 微信要求 HTTPS + 用户点击手势，确认链接是 `https://`，且是在点击"许愿"后才请求麦克风。
- **声音没声音？** 默认关闭，需点右上角"开启声音"；背景音乐没配文件时会用内置轻音乐盒，需先把手机音量调出。
- **想改插画/配色？** 房间插画在 `index.html` 的 `<svg id="room-svg">` 里，主色在 `css/style.css` 顶部的 `:root` 变量里。
